# Roadmap and Contribution Ideas

The following ideas are proposals, not promises or assigned issues. If you want to work on one, open a GitHub issue describing a small scope and proposed test cases.

## Good first issues

1. **Test detection for Java and Go:** Add conventional file naming patterns with small fixture tests.
2. **Handle case-insensitive template names:** Improve detection of PR templates across operating systems.
3. **Improve score documentation:** Add an illustrated breakdown of weighted scoring and ignored checks.
4. **Add useful examples:** Document use in pre-commit hooks and as part of a GitHub Actions step.

## Larger ideas

- Config file for customizable check weights and ignored checks.
- A plugin interface for language-specific checkers.
- A reusable GitHub Action wrapper for the CLI.
- Export standard machine-readable results for dashboards.

Keep additions offline, read-only, well tested, and clear about limitations.
