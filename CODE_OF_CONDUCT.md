# Community Code of Conduct

We welcome contributors of different backgrounds, experience levels, and viewpoints. Treat others with respect; discuss the work, not personal characteristics.

Harassment, threats, hateful language, sharing private information, and deliberate disruption are not accepted. Be constructive in code reviews, respect maintainers' time, and assume good faith while checking facts.

Report a concern privately to a repository maintainer through GitHub's reporting and moderation features. Maintainers may edit or remove inappropriate comments, close abusive issues, or restrict participation to protect the community.
