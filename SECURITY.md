# Security Policy

Repo Ready does not execute repository code, connect to the network, or read file contents. However, its own behavior may have security flaws.

**Do not post vulnerabilities publicly before maintainers have had a chance to respond.** Once the repository is published, use GitHub's **Report a vulnerability** feature under the repository's Security tab if enabled. Otherwise, privately contact the repository owner using a verified contact method on their GitHub profile. Do not paste private tokens or sensitive files into public issues.

Please include the affected version, minimal reproduction, impact, and a safe way to verify the issue.

Supported version: the latest version on the `main` branch.
